# PS6OS

PS6OS is a fan-made interactive web operating-system concept inspired by the navigation style, spatial hierarchy, quick controls, cards and cinematic presentation found in modern console interfaces.

This project is not affiliated with or endorsed by Sony Interactive Entertainment.

## Features

- Animated startup experience
- Cinematic game-focused home screen
- Interactive game carousel
- Game Library
- Store concept page
- Friends / Game Base
- Media hub
- Search overlay
- Notification center
- Profile panel
- Full-screen Settings app
- Control Center / quick menu
- Simulated sound controls
- Theme switch
- Power menu
- Keyboard navigation
- Responsive desktop/tablet/mobile layout

## Keyboard shortcuts

- Left / Right arrow: switch selected home game
- Q: open Control Center
- /: open Search
- Escape: close the active overlay

## Development

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
